# Security Policy

## Reporting a vulnerability

Report security vulnerabilities privately. Do not open a public GitHub issue.

Use either of these channels:

- GitHub private vulnerability reporting for this repository
- https://kestrelridgehealth.com/contact/

We will acknowledge a report within 5 business days.

## Patient data

Never include patient data or protected health information (PHI) in a report, attachment, or follow-up.

Kestrel Ridge Health (KRH) is not HIPAA certified and does not accept, store, or process patient data.
